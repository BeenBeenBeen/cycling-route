# V2.0 路线规划与 GPX 实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**目标：** 在现有骑行路线发布工具上增量实现 V2.0：起终点地点搜索、高德骑行路线规划、Open-Elevation 累计爬升计算、GPX 路书下载，以及前端完整工作流接入。

**架构：** 保持现有 `domain -> useCases -> routes -> services -> client` 分层，不推翻 V1 发布链路。V2.0 作为上游路线规划流程，生成并填充现有 `RouteInput`，然后继续复用 `/api/generate-post`、`/api/generate-cover`、`/api/save-markdown` 和 `/api/assist-publish`。高德地图、Open-Elevation、坐标转换、路线采样、GPX 写入都隔离在 service 层，测试中使用 fake 依赖替代真实上游。

**技术栈：** TypeScript、Vue 3、Express 5、Zod 4、Vitest、Supertest、Vite、Node `fetch`/`undici`、现有 JSON logger。
